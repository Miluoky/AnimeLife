# Anime

Сайт для просмотра аниме. Дизайн: тёмная тема «Ночной кинотеатр», акцент `#FF5470`, шрифты Unbounded и Manrope.

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в dist/
```

## Что есть

- `/` — главная: подборка недели, «Продолжить просмотр», каталог с фильтром по жанрам и поиском
- `/anime/:id` — страница тайтла со списком серий
- `/watch/:id/:episode` — плеер с выбором серии, озвучки и качества

Пока данные демонстрационные (`src/data/catalog.ts`), а вместо постеров и видео стоят заглушки.
